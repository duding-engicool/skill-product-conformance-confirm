# 产品一致性确认（product-conformance-confirm）

面向质量工程师、认证合规工程师的产品一致性确认技能。按统一维度框架比对产品与型式批准/认证标准的一致性，生成含维度比对表的一致性确认报告，输出 **文字版(.txt) + Markdown(.md) 文档**（无网页/办公格式，重实效、不花哨）。

## 适用角色
- 质量工程师（QE）
- 认证 / 合规工程师

## 核心能力
- 五类确认：公告参数 / 3C 关键件 / COP 执行 / 标志合规 / 供应商变更影响。
- 统一维度比对表（基准值 / 实测值 / 偏差 / 结论）。
- 偏差清单 + 整改建议 + 风险等级。
- 输出文字版(.txt) + Markdown(.md) 文档（无网页/办公格式）。

## 使用流程
1. 确认类型与产品标识（车型/产品、VIN、生产日期）。
2. 加载基准（公告参数 / CCC 证书 / COP 项目 / 标志样式）。
3. 逐维度比对，记录偏差，判定 一致/偏差。
4. 汇总通过/偏差项数与风险，列整改。
5. 调用 `scripts/build_report.py` 输出文字版与 MD 文档。

## 脚本说明（scripts/build_report.py）
- `python scripts/build_report.py` —— 使用内置小样本（含 1 项偏差示例），产出 txt+md。
- `python scripts/build_report.py --data-file confirm.json` —— 自定义数据。
- `python scripts/build_report.py --out-dir D:/临时` —— 指定输出目录（默认当前工作目录）。
- 输出：`conformance_report.txt`（纯文字版）与 `conformance_report.md`（Markdown）。无任何网页/办公格式。

## 能力边界
- 不替代认证/监管机构判定；不编造公告参数、证书编号、标准号。
- 基准值须引用企业/认证文件，未提供处标注「待企业补充」。
- 本技能不预置任何企业私有数据。

## 联动技能
- 表单生成（关键特性对齐）
- 计量管理（检测设备校准有效）
- 不合格处理（一致性偏差追溯）
- 内审不符合项（COP 未执行）
- 体系文件类技能
